# Standard schema sources

Copied without changes from `openusd-schemas` 0.8.0, whose standard schemas
come from Pixar OpenUSD v26.05. Only `usd` and `usdGeom` are needed to resolve
the project schema source's sublayers during native build-time generation.
The application reads standard declarations from `openusd-schemas`.
